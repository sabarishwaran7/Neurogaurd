Installation Guide

Download the extension Click the download button above to get the ZIP file.
Extract the ZIP Unzip the file to any folder on your computer.
Open Chrome Extensions Navigate to chrome://extensions/ in your browser.
Enable Developer Mode Toggle the switch in the top-right corner of the extensions page.
Load Unpacked Click "Load unpacked" and select the extracted neuroguard-extension folder.
Start browsing safely The extension is now active! Click the 🛡️ icon to see live analysis.
